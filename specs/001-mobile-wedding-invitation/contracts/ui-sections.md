# UI Contracts: 모바일 청첩장 섹션 구조

**Date**: 2026-04-24

## Page Structure (Top to Bottom)

이 문서는 Figma 디자인 기준 청첩장의 섹션 순서와 각 섹션의 UI 계약을 정의한다.

### 1. Header Section

- "Wedding Day" 타이틀 (스크립트 폰트)
- 신랑신부 메인 웨딩 사진 (전체 폭)
- 신랑/신부 이름: "지환, 인화"

### 2. Greeting Section

- 인사말 텍스트 (중앙 정렬)
- 결혼식 날짜: "2026년 7월 11일 토요일 오후 5시"
- 결혼식장: "노블발렌티 삼성"

### 3. Calendar Section

- 2026년 7월 달력
- 요일 헤더: Sun ~ Sat
- 결혼식 날짜(11일) 강조 표시 (원형 또는 배경색)

### 4. Family Info Section

- 신랑측: "김동희ㆍ조진숙 의 장남 지환"
- 신부측: "강대연ㆍ장옥분 의 장녀 인화"
- "연락하기" 버튼 → ContactModal 트리거

### 5. RSVP Section

- 안내 텍스트: "축하의 마음으로 참석해주실..."
- "참석 여부 전달하기" 버튼 → Google Form URL 새 탭/외부 이동

### 6. Gallery Section

- "GALLERY" 타이틀
- 사진 그리드 레이아웃
- 사진 탭 → 풀스크린 뷰어 (Swiper)
- 풀스크린에서 좌우 스와이프 네비게이션

### 7. Location Section

- "LOCATION" 타이틀
- 식장명: "노블발렌티 삼성"
- 주소 + Copy 버튼 (클립보드 복사)
- 카카오맵 임베드 (마커 표시)

### 8. Transportation Section

- **지하철**: 9호선 봉은사역 4번 출구 (도보 4분), 2호선 삼성역 8번 출구 (도보 15분)
- **버스**: 3417번, 강남01번 → 노블발렌티 정류장 하차
- **셔틀버스**: 봉은사역 5번 출구 우측 50~60m (5분 간격)
- **주차**: 본관 100대 (봉은사로 637), 별관 200대 (봉은사로 610)
- 각 교통편에 아이콘 + 소요시간 표시

## ContactModal Contract

**Trigger**: "연락하기" 버튼 클릭
**Behavior**: 모달 오버레이 표시

| 항목 | 이름 | 역할 | Actions |
|------|------|------|---------|
| 1 | 지환 | 신랑 | 📞 전화 / 💬 문자 |
| 2 | 인화 | 신부 | 📞 전화 / 💬 문자 |
| 3 | 김동희 | 신랑 아버지 | 📞 전화 / 💬 문자 |
| 4 | 조진숙 | 신랑 어머니 | 📞 전화 / 💬 문자 |
| 5 | 강대연 | 신부 아버지 | 📞 전화 / 💬 문자 |
| 6 | 장옥분 | 신부 어머니 | 📞 전화 / 💬 문자 |

- 전화: `tel:{phone}` URI
- 문자: `sms:{phone}` URI
- 모달 외부 클릭 또는 X 버튼으로 닫기
