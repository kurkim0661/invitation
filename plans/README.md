# Plans Directory

이 폴더는 구현 전에 합의한 방향, 범위, 우선순위를 정리하는 공간이다. 참고 자료 요약도 함께 보관한다.

## 언제 `plans/`를 쓰는가
- MVP 범위 정리
- 기능 우선순위 결정
- 기술 선택 이유 기록
- 단계별 개발 순서 메모

## 언제 `specs/`를 추가하는가
아래처럼 세부 동작이 구체화되면 `specs/` 폴더를 별도로 만든다.
- 섹션별 UI/카피 확정
- 컴포넌트 props/상태 정의
- 폼 흐름, 애니메이션, 반응형 규칙 명세
- 외부 연동 방식 세부화

현재 단계에서는 구조/범위 합의가 먼저이므로 `plans/` 중심으로 관리한다.

## 폴더 운영 원칙
- `plans/*.md` — 범위, 단계, 우선순위 문서
- `plans/materials/*.md` — 공식 사이트, 사용자 제공 자료 등 구현 참고용 정리본
- 원본 이미지/파일을 확보하면 나중에 `assets/`로 옮기고, 여기에는 출처와 요약만 남긴다.
